Cara dapat token
Cukup token — semua unit terpantau & ruas/peta otomatis dari data Wialon (AMORA). Token sama dengan Real Time Unit Position.

Cara mendapatkan token Wialon

Lewat Inspect · token permanen · tersimpan di browser Anda
  1. Buka lite.minervasuite.app, login, buka Monitoring sampai daftar unit muncul.
  2. Tekan F12 → buka tab Console.
  3. Klik Salin skrip, tempel ke Console, tekan Enter, tunggu.
  4. Di Console muncul TOKEN ANDA — salin barisnya.
  5. Kembali ke sini → tempel token → Connect.

  
Token dipakai bersama RTUP & Speed Watcher — cukup buat sekali.
